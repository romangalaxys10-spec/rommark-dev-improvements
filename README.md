## 🎨 Design Systems & Tech Stack

Each application was built without generic templates, adhering to tailored design guidelines:

- **Typography**: Paired Google Fonts matching each industry tone (`Cabinet Grotesk`, `Chakra Petch`, `Cormorant Garamond`, `Playfair Display`, `Cinzel`, `Space Grotesk`, `Teko`, `Plus Jakarta Sans`, `Inter`).
- **Styling**: Pure semantic HTML5, modern CSS3 variables, glassmorphism, responsive grid & flexbox systems, fluid clamp scaling.
- **Interactivity**: Pure Vanilla JavaScript with zero heavy framework bloat for maximum performance, sub-100ms load times, and instantaneous user feedback.
- **Theme Support**: Integrated dark/light mode toggles with persistent state.

All projects are pre-configured with Vercel configuration files.

```bash

./deploy-all.sh
```
